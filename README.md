# avito-anti-booked

Tampermonkey-скрипт для **Avito.ru**. Находит объявления с пометкой **«Забронировано»** и фильтрует объявления выбранных продавцов и брендов.

## ✨ Особенности
- 🔍 Поиск пометки «Забронировано» без привязки к автогенерируемым CSS-классам
- ⚡ Работа с динамической подгрузкой Avito
- 🛡️ Скрытие карточек без `display: none`, чтобы не ломать сетку выдачи
- 🎛️ Выбор режима для забронированных объявлений: скрытие или красная рамка
- 🚫 Чёрные списки продавцов и брендов с общим переключателем
- ⚫ Чёрная рамка у заблокированных объявлений, когда фильтр выключен
- 📝 Окно управления блокировками показывает имена продавцов и названия брендов
- 🌐 Совместимость с Tampermonkey, Violentmonkey и Greasemonkey

## 📦 Установка
1. Установите расширение **Tampermonkey** (или Violentmonkey) в ваш браузер.
2. В настройках **Tampermonkey** дайте доступ на выполнение пользовательских скриптов
3. Откройте вкладку «Создать новый скрипт».
4. Скопируйте код скрипта avito-anti-booked.js и вставьте в редактор.
5. Нажмите **Сохранить**.
6. Перейдите на `avito.ru` — скрипт начнёт работать автоматически.
7. Внизу страницы появится кнопка Скрыть/Показать

## 🔧 Как работает
- Для «Забронировано» скрипт ищет карточки по `data-marker="item"` и скрывает или подсвечивает их.
- Значок рядом со ссылкой профиля добавляет продавца в список. Значок рядом со ссылкой `/brands/...` добавляет бренд объявления.
- Брендовый список относится к брендам объявлений, а не к аккаунтам продавцов.
- «Списки user / brands» открывает окно с читаемыми именами и названиями. В нём можно открыть профиль или страницу бренда и удалить запись. Новые записи добавляются значками в карточках.
- «Фильтр» скрывает объявления из обоих списков. При выключенном фильтре объявления остаются в выдаче с чёрной рамкой.
- Фильтр «Забронировано» работает независимо от чёрного списка.
- `MutationObserver` пакетно обрабатывает изменившиеся карточки при динамической подгрузке.

## ⚠️ Дисклеймер
Скрипт не является официальным продуктом Avito и не связан с ним. Он изменяет только клиентскую часть страницы. Используйте на свой страх и риск.
